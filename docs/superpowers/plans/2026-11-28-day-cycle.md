# 하루 순환 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 전투 중 실제 초 단위로 시각이 흘러 시간대 프리셋(낮·노을·저녁·밤) 값이 섞여 들어가고, 해·달이 화면 위 가장자리(원반 1/3 만 보임)를 따라 움직이며 그림자가 따라간다.

**Architecture:** `TimeOfDayPreset` 리소스(.tres)에 시간 따라 바뀌는 무드 값과 시각을 둔다. BattleMood 가 `time_of_day` 로 앞뒤 프리셋을 선형 보간해 자기 값에 한 번에 넣고(`_apply` 한 번), 같은 시각으로 해·달(`SkyBody.is_moon`) 위치·보이기를 정한다. `time_flows` 면 `_process` 에서 `24 / day_length_sec` 시/초로 흐른다. 의뢰 전투면 전투 화면이 시각을 무작위로 준다.

**Tech Stack:** Godot 4.7.2, GDScript, GUT 9.7.1

**Spec:** `docs/superpowers/specs/2026-11-28-day-cycle-design.md`

## Global Constraints

- 순수 그래픽: 전투 규칙·전투 RNG(`battle_seed`·StageRun 시드)를 건드리지 않음. 무작위 시각은 전역 `randf()` 로
- 스크립트 `Scripts/backgrounds/`, 프리셋 데이터 `moods/time_of_day/*.tres`(공유), 배경 전용은 `moods/time_of_day/<배경>/`. 한국어 주석 (클래스·export·공개 함수 `##`)
- 에디터 켜짐: 씬 수정은 Godot AI MCP. 프리셋 .tres 는 `resource_manage(op="create", type="TimeOfDayPreset", resource_path=…, properties=…)` 로 생성(스크립트 리소스 patch 는 MCP 불가 → 값 바꿀 땐 overwrite 로 다시 생성). `battles/boss_battle.tres`(스크립트 리소스) 배경 교체는 **사용자에게 인스펙터 작업 안내** (Task 4)
- 테스트는 복사본 `../Void_testcopy` 에 동기화 후 (godot_ai 끔, `--log-file` 따로):
  `Godot_v4.7.2-stable_win64_console.exe --headless --path ../Void_testcopy -s res://addons/gut/gut_cmdln.gd -gdir=res://tests -ginclude_subdirs -gexit`
- `presets` 가 비면 BattleMood 는 지금과 똑같이 동작 (예전 배경 호환)
- 알려진 불안정 테스트: `test_battle_screen_layers.gd::test_screen_shake_moves_viewport_then_returns` (작업 전부터 간헐 실패)

## Review Focus

1. `presets` 가 1개뿐 → 그 값 그대로 (보간 대상 없음), 0개 → 인스펙터 값 그대로 (Task 1 테스트)
2. 시각이 마지막 프리셋 뒤~첫 프리셋 앞(자정 넘김) → 마지막과 첫 프리셋 사이 보간 (Task 1 테스트)
3. `day_length_sec` 0 또는 음수 → 흐르지 않음, 오류 없음 (Task 2 테스트)
4. 에디터에서 `time_flows` 켜 둠 → 에디터에서는 흐르지 않고(씬 파일에 시각이 계속 저장되는 것 방지) 게임에서만 흐름 (Task 2 테스트: `Engine.is_editor_hint()` 분기, 테스트는 흐름 쪽만)
5. 해와 달이 둘 다 화면 밖 → 해 없음 취급(그림자 짧게, 빛줄기 아래로) (Task 2 테스트)

**Interfaces:**
- Produces:
  - `class_name TimeOfDayPreset extends Resource` — `@export_range(0, 24, 0.1) var hour: float` + BattleMood 의 시간 따라 바뀌는 값과 **같은 이름·같은 기본값**의 export: `darkness, sky_top, sky_bottom, fill_color, fill_energy, fill_angle, light_scale, halo_scale, rays_color, rays_strength, fog_color, fog_density, vignette, split_tone, cool, warm, bloom, bloom_threshold, haze_color, haze_amount, shadow_color, shadow_length, shadow_fade` + `sun_color: Color`(해·달 원반 색)

  - BattleMood: `@export_group("시간대")` `@export var presets: Array[TimeOfDayPreset]`, `@export_range(0, 24, 0.01) var time_of_day := 18.0` (setter → `_apply_time()`)

  - `func _apply_time()` — presets 가 비면 아무것도 안 함. 아니면 blend 값을 setter 없이 넣고(`_batch` 플래그로 setter 의 `_apply` 막음) `_apply()` 한 번

### Task 2: 시간 흐름 + 해·달 궤도

**Files:**
- Modify: `Scripts/backgrounds/battle_mood.gd`, `Scripts/backgrounds/sky_body.gd`, `Scenes/backgrounds/parts/moon.tscn` (MCP: `is_moon = true`)
- Test: `tests/backgrounds/test_day_cycle.gd`

**Interfaces:**
- Consumes: Task 1 `_apply_time`, `blend_presets` (`sun_color`)
- Produces:
  - SkyBody: `@export var is_moon := false`
  - BattleMood: `@export var time_flows := true`, `@export_range(1, 3600, 1) var day_length_sec := 240.0` (사용자가 인스펙터에서 정함), `const SUNRISE := 6.0`, `const SUNSET := 18.0`
  - `static func body_position(hour: float, is_moon: bool, screen: Vector2, diameter: float) -> Variant` — 해는 SUNRISE~SUNSET, 달은 SUNSET~다음 SUNRISE 동안 왼쪽 밖(x = -diameter/2) → 오른쪽 밖(x = screen.x + diameter/2) 로 선형, y = **-diameter/6** (원반 1/3 이 화면 위 가장자리 안으로). 자기 시간이 아니면 `null`
  - `_process(delta)`: `time_flows and not Engine.is_editor_hint() and day_length_sec > 0` 이면 `time_of_day = fposmod(time_of_day + delta * 24.0 / day_length_sec, 24.0)`
  - `_apply_time()` 에서 해·달 배치: 부모 아래 SkyBody 마다 `body_position(time_of_day, b.is_moon, 화면 크기, b.body_size)` → null 이면 `visible = false`, 아니면 `position`·`visible = true`·`body_color = sun_color`(해만; 달은 그대로). 화면 크기 = 부모가 Control 이면 `size`, 아니면 `Vector2(1920, 1080)`

  - `test_body_position_moon`: hour 0 → x = 960; hour 12 → null

  - `test_zero_length_no_flow`: day_length 0 → 그대로
