# 소비 아이템 — 대상·범위·음수 효과, 웹 → Godot 가져오기 (설계)

날짜: 2026-11-17 · 상태: 승인 (2026-11-17)

## 왜

웹 카드 에디터의 소비 아이템 탭(2026-11-16)에서 아이템을 만들지만 Godot **카드 가져오기**가 `consumables` 를 읽지 않는다.
가져오기를 만들면서, 아이템을 적에게도 쓰고(폭탄·독약 같은 공격 아이템), 범위로 여러 명에게 쓰고,
수치를 음수로 둬서 HP·SP 를 깎을 수 있게 한다.

## 사용자가 정한 것 (2026-11-17)

- 웹에서 만든 소비 아이템을 Godot 에 가져온다
- **스탯 버프 줄은 일단 빼고 가져온다** (Godot 에 버프가 없음). 확인 창에 경고
- **효과 수치는 음수도 가능**
- 아이템마다 **사용 대상**: 아군 / 적 / 둘 다 중 선택
- 아이템에 **범위**를 정할 수 있다 (웹 에디터에서)
- 음수 HP 는 **피해가 아니라 HP 만 깎는다** (방어도 무시, 피격 효과 발동 없음)

## 목표

1. 웹 에디터: 소비 아이템에 사용 대상·범위를 정하고, 회복 수치에 음수를 넣을 수 있다. 내보내기에 담긴다
2. Godot: 카드 가져오기 한 번으로 소비 아이템이 `items/consumables/<이름>.tres` 에 생기거나 갱신된다
3. 전투: 아이템을 적에게도 끌어다 쓸 수 있고, 범위 안의 유닛 모두에게 효과가 들어가며, 음수 효과는 HP·SP 를 깎는다

## 하지 않는 것

- 스탯 버프 효과 (버프를 만들 때 다시 가져오면 채워진다)
- Godot → 웹 내보내기에 소비 아이템 넣기
- 적의 아이템 사용, 죽은 유닛 되살리기
- 아이템 전용 연출

## 실패로 보는 것

- 예전 zip(`consumables` 없음)이나 예전 아이템(대상·범위 없음)을 가져올 때 오류·삭제가 생김
- id 없는 시험 아이템(회복약·기력약)이 바뀌거나 지워짐
- 다시 가져올 때 Godot 에서 붙인 `effects` 가 사라짐
- 기존 아이템(아군 회복약)의 동작이 달라짐
- 카드·장비 가져오기 결과가 달라짐
- 음수 HP 효과가 방어도를 깎거나 "피해를 받으면" 계열 효과를 발동시킴

## 접근

- **채택**: 웹 데이터에 `target`·`area` 칸을 더하고, Godot `ConsumableData` 에 같은 칸을 둔다. 가져오기는 `EquipmentImporter` 와 같은
  모양의 `ConsumableImporter`(`addons/card_importer/consumable_importer.gd`). 음수는 기존 효과 줄(`HEAL_HP`/`HEAL_SP`)의 `amount` 가
  음수인 것으로 표현한다 — 웹 형식과 1:1 이고 새 종류가 필요 없다.
- 기각: "HP 감소"·"SP 감소" 효과 종류를 따로 만들기 — 웹 형식을 바꿔야 하고, 사용자는 "음수 수치"로 말했다.
- 기각: 음수 HP 를 피해(`Battle` 의 피해 처리)로 처리 — 사용자 결정으로 HP 만 깎는다.
- 기각: 버프까지 이번에 만들기 / 버프 든 아이템 건너뛰기 — 사용자 결정.
- 순서: **웹 에디터 먼저** (데이터 모양을 정함) → Godot 가져오기 → 전투 규칙·화면.

## 1. 웹 에디터 (아티팩트 https://claude.ai/artifact/T2zETQHPfWew1HejtgHKHd)

```
사용 대상   [아군] [적] [둘 다]
범위        5×5 격자 (카드 편집 창과 같은 부품, 가운데 = 고른 유닛, 안 고르면 한 명)
효과        [HP 회복 ▾] [고정|%] [-20]
```

- `target`: `"ally" | "enemy" | "both"`, 기본 `"ally"` (예전 문서도 ally 로 읽음)
- `area`: 카드와 같은 `[[x, y], …]` 오프셋 (−2..2). 비면 단일
- 회복 수치 검증: 정수면 통과 (음수 허용). 버프 검증은 그대로
- 효과 표시: 음수면 `HP 회복 -20` (지금 `formatEffect` 가 이미 부호를 붙임)
- 아이템 카드 미리보기: 대상 배지(`아`/`적`/`양`)와 범위 미니 격자 (카드와 같은 모양)
- 내보내기 `consumables[]` 에 `target`, `area` 추가. 가져오기(zip → 웹)도 두 칸을 읽는다
- Node 순수 함수 테스트(scratchpad) → 같은 URL 로 다시 게시

## 2. Godot 데이터

`ConsumableData` 에 웹 담당 칸 추가:

| 칸 | 내용 |
|---|---|
| `target: Target` | `ALLY` / `ENEMY` / `BOTH`, 기본 `ALLY` (기존 .tres 는 그대로 아군) |
| `area: Array[Vector2i]` | 범위 오프셋. 비면 단일. 인스펙터 편집은 카드의 5×5 격자 편집기를 쓸 수 있으면 쓴다 |

`ConsumableLine.amount` 는 음수 허용으로 바뀐다. `amount_for` 규칙:
- 고정: `amount` 그대로
- %: `대상 최대치 × |amount| / 100` 내림, 부호는 `amount` 를 따름
- 결과가 양수면 최소 1 (지금 규칙), 음수면 최대 −1, `amount == 0` 이면 0 (아무 일 없음)
- `describe()`: `HP 회복 -20`, `SP 회복 -10%`

## 3. 가져오기 (`ConsumableImporter`)

- 저장: `items/consumables/<이름>.tres`, 겹치면 `<이름>_<id>.tres` (id 없는 기존 파일과 겹쳐도)
- 웹 칸만 덮어쓴다: `id`, 이름·설명(한/영), `keywords`, `art`, `target`, `area`, `lines`. `effects` 는 유지
- 효과 줄: `heal_hp` → `HEAL_HP`, `heal_sp` → `HEAL_SP`, `kind: "percent"` → `PERCENT` (그 밖 `FLAT`), `amount` 정수
  - `buff` 와 모르는 종류는 버리고 아이템별로 버린 줄 수를 센다
- `target` 모르는 값 → `ALLY`. `area` 는 −2..2 밖·중복 칸을 버린다
- 파일은 파일 안의 id 로 찾고, 이름이 바뀌면 옮겨 uid 유지
- zip 에 없는 아이템(id 있는 파일)은 지운다. 가방은 파일로 남지 않으므로 "사용 중이라 남김" 없음
- id 없는 파일은 건드리지 않는다. `consumables` 키가 없으면 아무것도 바꾸지 않는다
- 그림: `items/consumables/art/<파일 이름>`, 안 쓰인 그림은 지운다
- 확인 창 (`plugin.gd`):

```
소비 아이템
추가 1개: 폭탄
덮어쓰기 0개: -
삭제 0개: -
⚠ 버프 효과는 아직 Godot 에 없어 빼고 가져옴: 힘의 물약(1줄)
```

삭제 목록에서 Godot `effects` 가 있는 아이템은 장비처럼 앞에 ⚠.

## 4. 전투 규칙 (`Battle.use_item`, `BattleSession`)

- 고를 수 있는 유닛: 살아 있는 유닛 중 `target` 에 맞는 편 (아군 / 적 / 둘 다). 사용 시점 규칙은 그대로 (아군 차례 카드 사용 페이즈)
- 범위: 고른 유닛 칸 + `area` 오프셋, **고른 유닛과 같은 편의 격자에서만**, 살아 있는 유닛만. 카드 광역과 같은 좌표 규칙. 범위 안에 받을 유닛이 없으면 그 유닛은 고를 수 없다 (리뷰 반영)
- 각 대상에게 효과 줄을 위에서부터:
  - HP 양수: 지금처럼 회복 (최대 HP 까지)
  - **HP 음수: HP 를 그만큼 깎는다. 피해가 아니다** — 방어도 무시, 피해 이벤트·"피해를 받으면" 계열·스태미너·치명 없음. 0 밑으로 안 감.
    0 이 되면 쓰러짐 (사망 처리는 기존 규칙). 아무도 준 것이 아님
  - SP 양수: 지금처럼 (최대 SP 를 넘어도 됨)
  - **SP 음수: SP 를 깎는다. 0 밑으로 안 감**
- 그다음 `effects` 를 대상마다 실행 (지금과 같음, 주인 = 그 대상)
- 사용 뒤 전투 종료 확인 (적 전멸이면 승리 — 지금 규칙)
- 전투 기록: `아이템: 폭탄 → 고블린` (범위면 대상 이름을 쉼표로)

## 5. 전투 화면

- 아이템을 끌 때 쓸 수 있는 유닛(위 규칙의 편)이 빛난다 — 적도 포함
- 범위 아이템은 카드처럼, 끌고 있는 대상 위에 범위가 표시된다 (카드 광역 표시를 그대로 쓴다)
- HP 감소 숫자는 기존 숫자 표시를 쓴다 (색은 기존 피해 숫자와 같게 할지 빌더가 맞춤)

## 내 판단으로 정한 것 (틀리면 고칠 것)

- 대상·범위가 없는 예전 아이템은 아군·단일
- 범위는 고른 유닛과 같은 편에만 (둘 다 아이템이라도 한 번에 양쪽에 걸치지 않음)
- % 음수는 최대치 × |%| 내림 후 부호, 최소 1 칸 규칙은 양·음 대칭
- 음수 SP 는 0 에서 멈춤
- 아이템 카드 미리보기의 대상 배지 글자 (`아`/`적`/`양`)
