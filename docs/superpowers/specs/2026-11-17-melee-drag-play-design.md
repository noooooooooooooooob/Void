# 근접 카드 끌어 올려 쓰기 — 설계 (2026-11-17)

## 의도
대상을 고를 필요가 없는 카드(자신·근접)는 그냥 끌어서 놓으면 쓰이게 한다. 자신 카드는 이미 된다. 근접 카드는 자동 대상 위에서 놓아야만 쓰여 번거롭다.

## 결정
- 근접 카드도 자신 카드와 같은 규칙: 위로 `drag_play_height` 넘게 끌어 올린 뒤 놓으면 자동 대상(같은 행 맨 앞 적)에게 사용
- 적 위에서 놓는 기존 방식도 유지
- 기준 높이 위로 올렸을 때 근접 카드의 화살표는 "쓸 수 있음" 색
- 원거리·아군 카드, 소비 아이템은 변경 없음 (대상 위에서 놓아야 함)

## 접근법
- **채택**: 자신 카드의 높이 기준을 함께 씀 — 잘못 놓았을 때 취소(손패 복귀)가 그대로 살아 있고 규칙이 하나로 통일됨
- 기각: 손패 밖 아무 데서나 놓으면 사용 — 취소할 방법이 없어져 2026-11-15 결정("대상 밖에서 놓으면 손패로 돌아감")과 충돌
