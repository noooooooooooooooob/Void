# 소비 아이템 에디터 — 웹 카드 에디터에 소비 아이템 탭 추가 (설계)

날짜: 2026-11-16 · 상태: 구현됨 (Godot 가져오기는 `2026-11-17-consumable-targets-design.md`)

## 왜

HP 즉시 회복 물약처럼 "쓰면 효과가 나고 없어지는" 아이템을 카드·장비와 같은 곳(웹 카드 에디터
아티팩트 "Project Void 카드", https://claude.ai/artifact/T2zETQHPfWew1HejtgHKHd)에서 만들고 관리하고 싶다.

## 목표

- 상단 탭에 **소비 아이템** 추가. 장비 탭과 같은 구성: 그리드 + 이름 검색 + 정렬(이름순 / 직접 정렬) + "새 아이템" 버튼, 편집은 오른쪽 시트 + 미리보기
- 아이템이 가진 것: 이름(한·영), 설명(한·영), 그림, 키워드(카드와 같은 목록), **효과 줄** 여러 개
- 효과 줄 종류
  - **HP 회복** — [+ 고정 | %] [수치]  (% = 최대 HP 기준)
  - **SP 회복** — [+ 고정 | %] [수치]  (% = 최대 SP 기준)
  - **스탯 버프** — [스탯] [+ 고정 | %] [수치] [지속 턴]  (스탯 목록 = 장비 STATS)
- 특수 효과는 설명 글로만 적고 실제 동작은 Godot 에서 붙인다 (장비와 같은 분담)
- 내보내기 zip 의 `cards.json` 에 `consumables` 키 추가, 가져오기도 읽는다 (카드·장비와 같은 규칙: 추가·변경만, 삭제 없음, 그림 없으면 기존 그림 유지)
- 키워드 탭의 "사용 수"에 소비 아이템도 센다. 그림 삭제 시 공유 검사에 소비 아이템도 포함

## 하지 않는 것

- 등급 (사용자 결정: 필요 없음)
- Godot 쪽 `ConsumableData`·가져오기 코드 — 이번엔 에디터와 JSON 형식까지만. Godot 작업은 별도로 진행
- 사용 횟수·최대 소지 개수, 상점·보상

## 실패로 보는 것

- 소비 아이템을 넣으면서 기존 카드·장비·키워드 저장/내보내기/가져오기 동작이 바뀜
- `consumables` 키가 없는 예전 zip 을 가져올 때 오류

## 접근

- **채택: 장비 탭 구조를 복제해 새 컬렉션 `consumables` 로 만든다.** 이미 검증된 패턴이고 코드 스타일이 그대로 이어진다.
- 기각: 장비에 `slot: "consumable"` 을 추가 — 장비의 "착용하면 항상 적용" 스탯과 "쓰면 한 번" 효과는 의미가 달라 Godot 쪽에서 섞이고, 등급 필드도 억지로 남는다.
- 기각: 카드 분류에 "아이템" 추가 — SP·코스트·범위 등 쓸모없는 칸이 딸려 온다.

## 데이터

db 컬렉션 `consumables`, 문서:
```json
{ "name": "", "nameEn": "", "description": "", "descriptionEn": "",
  "effects": [
    { "type": "heal_hp", "kind": "flat", "amount": 30 },
    { "type": "heal_sp", "kind": "percent", "amount": 20 },
    { "type": "buff", "stat": "attack", "kind": "flat", "amount": 5, "turns": 3 }
  ],
  "keywords": ["kw_id"], "illustration": "<asset id>" | null, "createdAt": 0, "order": 0 }
```
검증: 이름 필수, amount 정수(회복은 0 이상, 버프는 음수 허용), turns 1 이상 정수.

zip `cards.json`:
```json
"consumables": [{
  "id": "...", "name": {"ko": "", "en": ""}, "description": {"ko": "", "en": ""},
  "effects": [ ...위와 같음 ... ], "keywords": ["kw_id"], "art": "art/<파일>" | null
}]
```

## 카드 모양

장비 카드와 같은 틀, 테두리는 초록(새 토큰 `--consumable`, 노말 장비의 회색과 구분), 그림 위 태그 "소비".
효과 줄 표시: `HP 회복 +30`, `SP 회복 +20%`, `공격 +5 (3턴)`.

## 빌더에게 맡기는 것 (내 판단)

- 버튼 문구 "새 아이템", 탭 문구 "소비 아이템"
- 효과 줄 기본값: 새 줄 추가 시 `HP 회복 +고정 0`
- 검증: Node 로 CardModel 순수 함수 테스트 (scratchpad), 아티팩트에서 직접 확인
