# 캐릭터 페이지(사원 명부) 설계

작성: 2026-11-08 · 브랜치 `feat/office-hub` · 기준 그림: 사용자 목업(브람 캐릭터 화면)

## 1. 목적
사원 명부를 목업처럼 바꾼다: 왼쪽 초상 목록, 가운데 큰 일러스트 + 프로필(픽셀 캐릭터, 나이·키·소속·역할, 설명, 특성), 오른쪽 캐릭터 덱(쪽 넘기기).
사무소의 모든 캐릭터(10명)를 일러스트·픽셀 그림과 함께 보여준다.

## 2. 목표 / 비목표
목표
- 캐릭터 10명: 홍연, 하연, 세리안, 청운, 파빌라, 줄리안 마르소, 모량, 에드먼드, 브람 웰번, 주인공
- 캐릭터마다 일러스트(큰 그림)·픽셀(작은 그림)·초상(목록용, 일러스트의 얼굴 부분)
- 위쪽 탭 줄: 캐릭터(지금 화면) · 덱 · 장비 · 기록 · 설정 — 캐릭터 말고는 "준비 중"
- 덱은 한 쪽에 8장(4×2), 쪽 넘기기

비목표
- 덱 편집(연필 버튼 자리만), 장비·기록 탭 내용, 목업의 장식 테두리 그림(색 상자로 비슷하게)

## 3. 데이터
### 3.1 `CharacterProfile` (Resource, `Scripts/characters/character_profile.gd`, 파일 `entities/characters/<id>.tres`)
| 칸 | 뜻 |
|---|---|
| `id`, `display_name` | 고유 이름, 화면 이름 |
| `role`, `affiliation`, `age`, `height` | 프로필 칸 (글자, 모르면 "미정") |
| `description` | 설명 |
| `traits` | 특성 이름 목록 |
| `illustration`, `pixel` | 큰 그림, 픽셀 그림 (`Art/characters/<id>/`) |
| `portrait` | 목록용 얼굴 — 일러스트를 잘라 쓰는 `AtlasTexture` (자르는 범위는 인스펙터에서 조정) |
| `unit` | 전투 유닛(`UnitData`). 없으면 아직 전투에 못 나감, 덱 "미정" |

### 3.2 `RosterData` 변경
- `units` → `characters: Array[CharacterProfile]`. `playable_units()` = 유닛이 있는 캐릭터의 유닛 (파티는 여기서 앞에서부터)
- 유닛이 있는 캐릭터: 홍연(`test_hongyeon` — 전투되는 시험 덱), 파빌라(새 `entities/units/favilla.tres`, 덱 = 불씨 무녀 카드 9장, 스탯 기본값)

### 3.3 프로필 글
- 설정집(Project Void 설정집 아티팩트)의 확정·후보 내용으로 짧게. 나이·키는 브람(목업 값)만 넣고 나머지는 "미정"
- **임시 문구** — 노션 등장인물 표가 정해지면 바꾼다

## 4. 그림
- 후보 그림 전부(`ProjectVoid_Assets/characters/`, 약 49MB) → `Art_src/characters/` (원본·후보 보관, Godot 무시)
- 캐릭터마다 1장씩 골라 → `Art/characters/<id>/<id>_illust.png`, `<id>_pixel.png` (게임이 씀). 픽셀 그림이 없는 모량·브람은 비워 둠
- 픽셀 그림을 그리는 노드는 Texture Filter = Nearest (CLAUDE.md)

## 5. 화면 (`Scenes/ui/roster/roster.tscn`, 1920×1080)
```
[← 뒤로] [ 캐릭터 | 덱 | 장비 | 기록 | 설정 ]
┌초상┐ ┌──────── 프로필(양피지색) ────────┐ ┌──── 캐릭터 덱 ────┐
│ ▲  │ │ 큰 일러스트   [캐릭터 프로필]      │ │ 덱 이름   10장 ✎ │
│ 얼굴│ │              [픽셀] 나이/키/소속/역할│ │ 카드 4×2         │
│ 얼굴│ │              [설명]               │ │                  │
│ ... │ │              [특성 칩]             │ │   ‹  1/2  ›      │
│ ▼  │ └───────────────────────────────────┘ └──────────────────┘
```
- 초상 버튼 고르면 가운데·오른쪽이 그 캐릭터로. 고른 초상은 금색 테두리. W/S·↑/↓ 로도 이동

## 6. 테스트
- 캐릭터 데이터 10개가 다 열리고 이름·일러스트·초상이 있다
- 명부 `playable_units()` 첫 번째 = 홍연 시험 유닛 (기존 파티 테스트 유지)
- 화면: 초상 버튼 10개, 고르면 이름·일러스트·픽셀이 바뀜, 덱 8장/쪽 + 쪽 넘기기, 유닛 없는 캐릭터는 "덱 미정"
