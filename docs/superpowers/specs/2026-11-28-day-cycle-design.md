# 하루 순환 (시간대 프리셋 + 해·달 이동) — 설계 (2026-11-28)

전투 무드 다음 단계 "B. 시간대 프리셋"을 실시간 하루 순환으로 (`docs/superpowers/plans/2026-11-27-battle-mood-next-handoff.md`).

## 왜
- **게임 규칙에는 영향 없는 순수 그래픽** (사용자): 전투 화면이 입체적이고 살아 있게. 전투 한 판 동안 실제 초 단위로 시간이 흐르고, 해·달이 하늘을 천천히 미끄러지며 장면 색과 그림자가 따라 변한다
- 레퍼런스: 용사주식회사 「배틀씬 또 고쳤습니다」 프레임 8 낮 / 9 노을 / 10~11 저녁 / 12 밤

## 목표
- **시간대 프리셋 4개** (낮·노을·저녁·밤) = 무드 값 묶음 `.tres`. 시작값은 레퍼런스 프레임 8·9·11·12 느낌으로 맞추고 화면 확인 보고
- BattleMood 에 **지금 시각**(0~24시, 인스펙터 슬라이더) — 가까운 두 프리셋 값을 섞어 무드에 넣는다. 에디터에서 슬라이더를 끌면 모든 시간대를 바로 미리 봄
- **하루 한 바퀴 시간(초)을 인스펙터에서** (사용자 결정). 시간 흐름 켜기/끄기 (끄면 지금 시각에 고정)
- **해·달 이동** — 시각에서 위치 계산. 궤도는 **화면 위쪽 바깥**을 지나는 호이고 **원반의 약 1/3 만 화면에 보인다** (사용자 결정). 해는 낮 동안(대략 6시 왼쪽 → 12시 가운데 → 18시 오른쪽), 달은 밤 동안 같은 궤도. 화면 밖으로 다 나가면 안 보이는 것으로 친다(빛줄기·그림자 기준에서 빠짐)
- **그림자**: 지금 해(밤엔 달) 반대쪽으로. 길이·진하기·색은 프리셋 값(낮 짧고 진함, 노을 길게, 밤 옅게). 순환 내내 화면으로 확인
- **시작 시각**: 의뢰의 전투 노드(`StageRun.is_active()`)에서는 **무작위** (사용자 결정). 그 밖(F6 시험 전투·에디터)은 배경의 BattleMood 에 정한 시각
- 특정 배경 무드에 묶이지 않음 — 신사 정원도 순환을 쓴다 (사용자: "노을 신사정원 아니어도 됨")
- **배경별 세부 조절 = 프리셋 바꿔 끼우기** (사용자 결정 B, 바꿔 끼우기 방식): 기본은 공유 프리셋 4개. 한 배경만 다르게 하려면 그 시간대 프리셋을 복제해 고쳐 그 배경의 프리셋 목록에서 바꿔 끼운다. 신사 정원의 지금 노을 값은 신사 정원 전용 노을 프리셋으로 옮긴다
- **보스 전투도 신사 정원 배경** (사용자: 산 신사 `mountain_shrine.tscn` 은 이제 안 씀) — `battles/boss_battle.tres` 의 background 를 `shrine_garden.tscn` 으로. 산 신사 씬 파일 자체는 지우지 않음

## 비목표
- 게임 규칙·전투 결과에 영향 (순수 그래픽)
- 시간대별로 물품을 켜고 끄기(밤에만 켜지는 석등 등) — 밝기 배율로만
- 별·구름·날씨, 바닥 햇빛 조각(D)
- 산 신사 배경에 무드 넣기 (안 씀), 배경별 "보정 값 레이어"
- 이미 정한 비목표 유지: 배경 물체 그림자, 연출 "공중 높이" 키

## 접근 (사용자 선택: 1)
1. **시간대 프리셋 .tres + BattleMood 가 시각으로 섞기 (선택)** — 프리셋 하나 고치면 모든 배경에 반영, 에디터 시각 슬라이더로 미리 보기
2. 배경마다 AnimationPlayer 타임라인 — 눈으로 다듬기는 좋지만 배경마다 키를 다시 찍어야 하고 값이 흩어짐. 뺌

## 정한 것
- **프리셋 리소스** `TimeOfDayPreset` (`Scripts/backgrounds/time_of_day_preset.gd`, 데이터 `Scenes/backgrounds/parts/time_of_day/<day|dusk|evening|night>.tres` — 빌더가 데이터 폴더 위치를 프로젝트 규칙에 맞게 정해도 됨). 프리셋마다 **시각**(0~24)과 BattleMood 의 시간 따라 바뀌는 값: 어둠·하늘 위/아래·보조광 색/세기/각도·빛나는 물품 밝기/헤일로 배율·빛줄기 색/세기·안개 색/진하기·비네트·냉난 대비·차가운/따뜻한 색·빛 번짐/문턱·공기원근 색/비율·그림자 색/길이/끝 흐림. 해·달 원반 색도 프리셋에(지평선 근처 붉게)
- 섞기: 시각 기준으로 앞뒤 프리셋 사이를 선형 보간 (밤 → 낮은 24시를 넘어 이어짐)
- 시간 따라 안 바뀌는 값은 배경마다 그대로: 공기원근 대상·재질·흐림, 안개 속도, 그림자 바닥 기울기·해 없을 때 길이
- BattleMood 인스펙터: `time_of_day`(0~24), `day_length_sec`(하루 한 바퀴 초, 사용자가 정함), `time_flows`(켜기/끄기), `presets`(이 배경이 쓰는 프리셋 목록 — 기본은 공유 4개, 바꿔 끼우기로 배경 전용. 비면 지금처럼 인스펙터 값 그대로 = 예전 배경 호환)
- 해·달: 배경 씬의 sun·moon 부품을 BattleMood 가 시각에 맞춰 옮긴다. 궤도 기준은 화면 크기(1920×1080 배치 기준)와 원반 지름 — 원반 1/3 이 화면 위 가장자리 안쪽에 보이게
- 무작위 시작: 전투 화면이 배경을 띄울 때 `StageRun.is_active()` 이면 BattleMood 시각을 0~24 무작위로

## 빌더에게 남긴 것
- 프리셋 4개의 시각(예: 낮 12·노을 18·저녁 20·밤 0)과 실제 값 — 레퍼런스에 맞춰 화면 확인
- 궤도 모양(호의 휨, 양 끝이 화면 모서리 어디쯤인지), 해가 뜨고 지는 시각, 해·달이 둘 다 보이는 시간대 처리
- 하루 길이 기본값 (예: 240초)
- 시각이 흐를 때 매 프레임 넣을 값만 넣기 등 성능 처리
