# 바닥 그림자 — 설계 (2026-11-28)

전투 무드 다음 단계 "C. 캐릭터 그림자" (`docs/superpowers/plans/2026-11-27-battle-mood-next-handoff.md`).

## 왜
- 레퍼런스(용사주식회사 「배틀씬 또 고쳤습니다」 프레임 8·9): 낮엔 발밑 짧은 그림자, 노을엔 **해 반대쪽으로 긴 대각선 그림자**. 캐릭터가 바닥에 서 있는 느낌과 장면 시간대를 살린다
- 조절할 수 있는 건 인스펙터에서 (BattleMood 에 슬라이더)

## 목표
- 전투 유닛마다 자기 그림을 검게 눌러 바닥에 눕힌 그림자. **지금 재생 중인 동작·칸을 그대로 따라감** (idle·hit·attack, 그림 안에 그린 점프 포함)
- **방향은 해·달 위치에서 자동** (사용자 결정): 물체마다 "해 → 그 물체 발밑" 방향으로 뻗음 → 해에서 부채꼴로 퍼짐. 해를 옮기면 그림자도 돈다
- 길이·진하기·색·끝 흐림은 BattleMood 인스펙터에서. 해·달이 없으면 발밑에 짧게 (아래로 납작하게)
- 카드 연출 중에도 그림자: 연출 복사본(Actor)에도 같은 부품을 붙인다 (원래 그림은 연출 중 숨겨짐)
- **부품 하나로 재사용**: 나중에 따로 그린 석등·도리이 그림(Sprite2D)에도 같은 부품을 붙이면 그림자가 생기게

## 비목표
- 배경 물체(석등·도리이) 그림자 — 아트를 따로 그려 올릴 예정이라 **이번엔 안 함**. 부품이 정지 그림(Sprite2D)도 받게만 만든다
- 연출의 **공중 높이 키**(위치로 점프시킬 때 그림자는 바닥에 남게) — 지금은 안 함. 지금은 연출에서 Actor 위치를 위로 옮기면 그림자도 같이 뜬다. 필요해지면 "높이" 키를 따로 두는 방식으로 (사용자: 나중에 필요하면 변경)
- 계단·난간 위로 그림자가 꺾이는 것 (바닥은 평평하다고 봄), 그림자끼리 겹침 처리, 바닥 햇빛 조각(D)

## 접근 (사용자 선택: 1)
1. **그림 복사본을 눕히고 기울이기 (선택)** — 대상 그림과 같은 프레임을 그리는 노드를 발밑에 두고, 변환(Transform2D)으로 바닥에 눕혀 해 반대쪽으로 기울이고, 작은 셰이더로 검게 + 멀수록 옅게. 애니메이션을 그대로 따라가고 정지 그림에도 쓸 수 있고 에디터에서 바로 보임. 평평한 바닥 가정
2. 셰이더 하나로 투영 계산 — 더 유연하지만 에디터에서 자리·크기를 보기 어렵고, 지금 필요한 모양엔 1 로 충분
- 뺀 것: Godot 2D 빛 그림자(LightOccluder2D) — 화면 평면에서 빛을 가리는 위에서 본 방식이라 옆에서 본 바닥 그림자에 안 맞음

## 정한 것
- **부품**: `Scenes/backgrounds/parts/ground_shadow.tscn` + `Scripts/backgrounds/ground_shadow.gd` (`@tool`). 대상 그림(AnimatedSprite2D 또는 Sprite2D)의 **자식**으로 두고 `show_behind_parent` — 대상의 위치·배율·좌우 뒤집기·보이기를 그대로 받음 (연출 중 원래 그림이 숨으면 그림자도 숨음). 원점 = 대상의 발밑(전투 그림은 발밑 피벗 규약)
- 대상이 AnimatedSprite2D 면 sprite_frames·animation·frame·flip 을 매 프레임 따라 맞추고, Sprite2D 면 texture·region·flip 을 맞춘다
- **투영**: 그림 안 높이 h 인 점 → 발밑에서 `h × 길이 × d` 만큼 떨어진 바닥 점. d = (발밑 − 해) 방향, 화면 세로는 바닥 기울기 값만큼 눌러 줌. 대상의 배율로 나눠 대상 기준 좌표로 넣는다
- **빛**: 그림자는 빛을 안 받음 (light_mask 0) — 캐릭터 보조광에 밝아지지 않게. 어둠(CanvasModulate)은 받음
- **BattleMood 에 "그림자" 그룹** 슬라이더: 색, 진하기(알파), 길이(대상 키 대비 배율), 끝 흐림(멀어질수록 옅어지는 정도), 바닥 기울기(세로 누름), 해·달 없을 때 길이. 값을 바꾸거나 해·달이 움직이면 그림자들이 바로 따라감
- **BattleMood 가 그림자를 찾는 범위**: 유닛·연출은 배경 씬 밖(전투 화면)에 있으므로, 그림자 부품이 그룹으로 BattleMood 를 찾아 값과 해·달 위치를 받는다 (전투 화면에 BattleMood 가 없으면 해·달 없음 값으로 짧은 그림자). 지금 BattleMood 의 "부모 안 부품만" 규칙은 그림자에는 적용하지 않음
- **붙이는 곳**: `Scenes/ui/battle_screen/unit_token.tscn` 의 Sprite 아래 (에디터로). 연출 Actor 에는 연출 큐(`Scripts/ui/performance_queue.gd`)가 연출을 띄울 때 그림자 부품을 instantiate 해서 붙인다 — 기존·새 연출 씬을 하나하나 고치지 않게
