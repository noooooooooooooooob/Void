# 파티 선택 · 공용 ESC 메뉴 · 사선 전투 화면 설계

작성: 2026-11-08 · 브랜치 `feat/office-hub`

## 1. 파티 선택 (`Scenes/ui/party_select/party_select.tscn`)
- 흐름: 공허 지도에서 "들어가기" → **파티 선택** → "출발" → 스테이지 지도. "뒤로" → 공허 지도
- 고를 수 있는 캐릭터 = 카드(전투 유닛)가 있는 캐릭터 (지금 홍연·파빌라·브람)
- 최대 `MAX_PARTY = 3`명 (설정집 후보 "출전 3명". 노션 규칙이 정해지면 바꾼다), 1명 이상이어야 출발
- 고른 순서대로 아군 앞줄에 선다: `StageRun.PARTY_CELLS` = (3,1) 가운데 → (3,0) 위 → (3,2) 아래
- `StageRun.start_run(site, seed, party)` — party 가 비면 명부의 전투 가능 캐릭터 앞에서부터 (개발용 바로가기)
- 파빌라·브람 카드는 아직 효과가 비어 있어서, 써도 피해·쉴드가 들어가지 않는다

## 2. 공용 ESC 메뉴 (`Scenes/ui/pause_menu/pause_menu.tscn`, `PauseMenu`)
- 화면마다 따로 만들지 않고 이 씬 하나를 넣어서 쓴다
- 버튼: 계속하기 · 전투 스킵(승리, 개발 빌드만) · 의뢰 포기(공허 지도로)
- 어떤 버튼을 보일지는 넣는 쪽 인스펙터의 `show_skip` / `show_abandon`
- 전투 화면: 계속하기 + 전투 스킵 + (의뢰 전투면) 의뢰 포기. 스테이지 지도: 계속하기 + 의뢰 포기
- 의뢰 포기 = 의뢰 실패와 같음 (정화 기록 없이 공허 지도로)

## 3. 사선 전투 화면
- 격자: 아군·적 격자(GridContainer)를 `AllyFloor`/`EnemyFloor`(Node2D) 안에 넣고 세로를 0.6배로 눌러 기울인다(skew). 칸 클릭·표시는 그대로
- 유닛: 칸 안이 아니라 기울지 않은 `UnitLayer` 위에 놓는다. 칸 가운데(기울어진 위치)에 발이 오게
- 아군 = 픽셀 캐릭터 그림(`UnitData.battle_sprite`) + 아래 이름표(이름·HP). 그림이 없는 유닛(적)은 지금처럼 네모
- 뒷줄 유닛이 앞줄 유닛 뒤에 그려지게 줄 순서대로 그린다
- 픽셀 그림은 Texture Filter Nearest

## 4. 테스트
- 파티 선택: 고를 수 있는 캐릭터 수 = 전투 유닛이 있는 캐릭터 수, 최대 3명, 0명이면 출발 불가, 출발 → 고른 순서대로 파티·자리
- ESC 메뉴: 전투에서 열기·닫기·스킵(기존), 스테이지 지도 ESC → 메뉴, 의뢰 포기 → 공허 지도·의뢰 끝
- 전투 화면: 유닛이 UnitLayer 에 있고, 그림 있는 유닛은 Sprite 가 보인다
