# 소비 아이템 특수 효과 — 분노 포션·쉴드 포션·폭탄 (2026-11-17)

## 왜
웹 에디터 효과 줄은 HP 회복·SP 회복·버프뿐이고 버프는 Godot 가 아직 못 받는다.
그래서 가져온 아이템 중 분노 포션·쉴드 포션·폭탄은 써도 아무 일이 없다. 이 셋을 실제로 동작하게 한다.

## 접근 (사용자 선택: A)
- **A. Godot 담당 칸 `ConsumableData.effects` 에 카드 효과 부품을 붙인다** ← 선택. 코드 변경 거의 없음, 다시 가져와도 유지.
  단점: 수치는 Godot 인스펙터에서 고치고, 웹 에디터 효과 줄에는 안 보인다.
- B. 웹 에디터에 피해·방어도 종류를 추가하고 가져오기·전투가 버프 줄까지 실행. 팀원이 웹에서 고칠 수 있지만 세 곳을 다 고쳐야 함.

## 정한 것
| 아이템 | 효과 (`effects`) | 출처 |
|---|---|---|
| 폭탄 | `DamageEffect` 고정 피해 10, 치명 없음. 범위(십자) 안 적마다 | 웹 설명 "10의 대미지" |
| 쉴드 포션 | `BlockEffect` 고정 방어도 **10** | 사용자: 고정값 / 수치 10 은 내 판단(폭탄과 맞춤) |
| 분노 포션 | `ApplyStatusEffect` → 새 상태 `statuses/data/rage_potion.tres` 1 부여 | 웹 버프 줄: 공격 +10%, 1턴 |

새 상태 **분노** (`rage_potion`, BUFF):
- 보정: 공격 +10% × 분노 수치 (두 번 마시면 +20% — 내 판단)
- **받은 유닛 자신의 엔드 페이즈에 전부 사라짐** (사용자 결정). 자기 차례에 마시면 그 차례 끝에 사라진다.
  트리거 END_PHASE / OWNER_IS_ACTOR → 수치 −1 × 현재 수치

## 규칙 (기존과 같음)
- 아이템 효과는 행위자 없음: 폭탄 피해는 상태 피해처럼 치명·스태미너 회복 없음, 방어도에는 막힘
- 분노 포션의 웹 버프 줄은 계속 가져올 때 빠진다 (가져오기 경고 그대로)

## 범위 밖
웹 에디터 수정, 버프 줄 가져오기, 효과 줄 표시(가방 툴팁에 특수 효과 설명 자동 생성)

## 만드는 방법
`.tres` 는 중첩 리소스라 MCP 로 못 만든다 → 에디터를 끈 상태에서 Godot 헤드리스 스크립트로 저장.
테스트: `tests/battle/test_items.gd` 에 실제 세 파일을 불러 써 보는 테스트 추가 (TDD).
