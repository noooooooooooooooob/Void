# 피격 반응 — hit 애니메이션 · 슬로우모션 · 연출 화면 미리보기 (2026-11-21)

## 의도
연출을 짤 때 맞는 쪽 반응까지 에디터 "연출 화면" 탭에서 보고, 게임의 피격 손맛을 히트스톱(정지) 대신 슬로우모션으로.

## 게임
1. **hit 애니메이션**: hit 키 때 대상 유닛 그림 묶음에 `hit` 애니메이션이 있으면 한 번 재생 → 끝나면 idle (`UnitToken` 의 기존 idle 복귀). 없으면 지금과 같음. (지금은 어느 유닛에도 없음 — 그림이 생기면 반복 없이 `hit` 를 넣으면 됨)
2. **히트스톱 → 슬로우모션**: hit 순간 연출(공격자·이펙트·이동)과 대상 그림을 `hitstop_speed` 배속으로 `hitstop_time` 초 동안. 기본 0.2배속·0.15초 (내 제안, 0.07초는 슬로우로는 느낌이 안 남). 공통값 `BattleScreen`, 카드별 `CardPerformance`(0 미만 = 공통값). 0배속 = 예전 정지

## 연출 화면 탭
3. 막대 끌기·▶ 둘 다: 직전 hit 키에서 지난 시간으로 적 그림의 번쩍임·넉백·흔들림(정해진 난수)·hit 애니메이션 프레임을 계산해 그림
4. ▶ 재생 중 막대가 hit 키를 지나는 순간: 효과음(공통값/카드별), 화면(무대 World) 흔들림, 슬로우모션(편집 중 연출 씬 AnimationPlayer `speed_scale` 을 잠깐 바꿨다 되돌림)

## 비목표
- 자동 피격 이펙트(`hit_effect`)를 연출 화면에 띄우기 — 사용자는 이펙트를 연출 씬 안에 노드+트랙으로 직접 짬(b안). 그런 노드는 Target 기준 자리 맞추기로 이미 대상 자리에 나오고 창도 그대로 그림
- 광역 대상마다 이펙트

## 접근
- 히트스톱: A(진짜 AnimationPlayer 속도 변경, 게임과 타이밍 같음 — 선택, 슬로우모션으로) / B(창 그림만 멈춤 — 타이밍이 게임과 달라 안 씀)
