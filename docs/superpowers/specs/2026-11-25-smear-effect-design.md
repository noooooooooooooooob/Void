# 스머지(스미어) 효과 — 설계 (2026-11-25)

## 의도
연출에서 행위자가 순간이동하거나 빠르게 움직일 때 "빠르다"는 느낌을 준다. 그림을 새로 그리지 않고, 지나온 쪽으로 그림이 늘어나 번지는 모션 블러 꼬리를 잠깐 그린다.
시험판(브람 돌주먹)으로 모양을 정했다 — 캡처 비교 후 사용자 선택.

## 목표
- 연출 씬에서 필요한 곳에 노드 하나를 붙이면 Actor 가 빠르게 움직일 때 자동으로 꼬리가 생긴다 (키를 찍을 필요 없음)
- 꼬리 모양 (사용자 선택): 그림 전체가 고르게 늘어남(`min_length` 1) + 짚은 색 평균(부드러운 블러) + 몸 위에 살짝 덮음(`front_amount` 0.2), 디더 없음
- 꼬리 길이 = 이동 거리 × `length_ratio`(0.5), 최대 `max_length`(400px). 길든 짧든 `decay_time`(0.12초) 안에 사라짐
- 카메라 이동에는 반응하지 않음 (연출 씬 루트 기준 위치)
- 실제 전투·연출 미리보기(F6)·에디터 연출 화면 탭에서 모두 보임. 편집 중인 씬에서는 돌지 않음 (재질이 씬 파일에 저장되지 않게)
- 일러스트(브람)·픽셀 아틀라스(홍연) 그림 모두 맞게 — 아틀라스 프레임은 그 프레임 영역 밖을 읽지 않음

## 하지 않는 것
- 유닛 박스 그림(칸 이동·넉백)에는 붙이지 않음
- 애니메이션 키로 켜고 끄기 — 나중에 필요하면 추가
- Actor 에 이미 재질이 있으면 덮어쓰지 않고 경고만 (지금 재질 쓰는 연출 없음)

## 방식 (고려한 것)
1. **연출 씬마다 필요하면 붙이기 (선택)** — 쓸 곳만, 연출마다 값 다르게. 붙이는 수고는 씬 하나 끌어다 놓기
2. 모든 연출에 자동 — 원하지 않는 연출에서 꺼야 함
3. 애니메이션 키로 켜고 끄기 — 정확하지만 키 찍는 수고. 나중에 1 위에 더할 수 있음

## 구조
- `Scripts/performances/smear.gdshader` — 그림 사각형을 사방으로 `pad` 만큼 넓히고, 픽셀마다 이동 앞쪽을 `samples` 번 짚어 평균 색을 꼬리로. 몸 뒤에 깔고 `front_amount` 만큼 몸 위에도. 줄무늬 모드(`min_length` < 1, `average` 끔)도 남겨 둠
  - UV 는 따로 넘김 (엔진이 fragment UV 를 그림 영역으로 잘라 여백에 가장자리 줄이 늘어지는 문제)
  - 그림 영역은 uniform `region`(정규화 Rect) 으로 받아 그 밖은 투명 — 아틀라스 프레임 대응
- `Scripts/performances/smear_driver.gd` (`SmearDriver`, `@tool`) — 부모 AnimatedSprite2D 에 ShaderMaterial 을 씌우고 매 프레임 이동 → 꼬리 벡터·짚는 수·현재 프레임 영역을 셰이더에 넣음
- `Scenes/performances/smear.tscn` — `SmearDriver` 노드 하나. 연출 씬의 Actor 아래에 인스턴스로 끌어다 놓음
- `bram_stone_fist.tscn` — 시험판의 `Actor/Smear` 노드를 이 씬 인스턴스로 바꿈 (에디터에서)

## 테스트 (GUT)
- 드라이버: 20px 미만 이동은 꼬리 없음 / 꼬리 = 이동 × 비율, 최대 길이 제한 / decay_time 안에 0 / 첫 프레임 이동 무시 / 좌우 반전 / 그림 배율 반영 / 이미 재질이 있으면 안 덮어씀 / 아틀라스 프레임 영역 전달
- 셰이더: 재질을 만들어 그릴 때 컴파일 에러 없음 (시험판에서 `TEXTURE` 함수 인자 에러를 테스트가 잡았음)
- 연출: 돌주먹 연출이 끝까지 재생되고 에러 없음 (기존 테스트)

## 빌더에게 맡김
- 셰이더 uniform 이름·순서, 짚는 수 계산식(지금 화면 8px 에 한 번, 4~48)
- `smear.tscn` 저장은 에디터 MCP 또는 에디터 끈 상태 헤드리스 (`.tscn` 손 작성 금지)
