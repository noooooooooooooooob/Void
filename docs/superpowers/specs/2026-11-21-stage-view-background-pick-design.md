# 연출 화면 — 배경 고르기 · 행위자/대상 칸 하나씩 (2026-11-21)

## 의도
에디터 "연출 화면" 탭(`addons/performance_stage_view`)에서 연출을 여러 배경 위에서 확인하고, 연출에 관계없는 아군·칸을 치워 화면을 깔끔하게 본다.

## 목표
- 위 줄에 **배경 목록**: `Scenes/backgrounds/` 의 `.tscn` 들. 기본 = 시험 전투의 배경. 고른 배경은 에디터를 다시 켜도 기억(에디터 프로젝트 메타데이터, 플러그인 담당)
- 배경을 바꾸면 무대를 다시 깐다. 격자 크기·칸 자리는 계속 시험 전투(`battles/test_battle.tres`) 기준
- **유닛은 행위자 하나 + 맞는 적 하나만**. 행위자 그림은 연출 씬이 열려 있으면 지금처럼 숨김(Actor 가 대신), 아닌 아군은 늘 숨김
- **격자 칸도 행위자 칸 하나 + 적 칸 하나만** 보임. 행위자를 바꾸면 보이는 칸도 바뀜

## 추가 (같은 날 사용자 요청)
- 행위자 목록 없앰 — 연출 카드의 주인으로 자동
- 유닛 박스는 그림 묶음이 없는 유닛만 (연출 중 행위자는 박스도 숨김 — 빈 박스가 남지 않게)
- **적 목록**: `entities/units/` 아래(하위 폴더 포함) UnitData 전부. 기본 = 시험 전투 첫 적, 서는 칸은 첫 적 칸. 고른 적은 플러그인이 기억

- **내 칸·적 칸 목록**: 시험 전투 격자 칸("열,행")에서 행위자·적이 설 칸을 고름. 기본 = 전투 데이터 자리, 행위자가 바뀌어도 고른 칸 유지, 플러그인이 기억
- **연출 위치 규칙 변경 (A안)**: `PerformanceSpace.map_point` — Target 쪽 1/3 은 실제 대상 기준 같은 픽셀, Home 쪽 1/3 은 실제 행위자 기준 같은 픽셀, 가운데 1/3 만 섞음. (B안: 순간이동 전용 Call Method 키 — 트랙과 따로 놀고 예전 move() 키로 돌아가는 셈이라 안 씀)
- 브람 돌주먹: 순간이동 (`Actor:position` Discrete 0 → 0.15초 대상 앞 50px → 0.6초 Home)

## 비목표
- 실제 게임·F6 미리보기 변경

## 접근
- A (선택): 창이 배경 목록을 갖고, 배경만 바꾼 BattleData 복제로 `set_battle` 을 다시 부름. 저장은 플러그인이 시그널을 받아 처리
- B: 전투 데이터(.tres)를 고르게 — 사용자는 배경을 고르길 원했고 전투 데이터는 지금 둘 다 같은 배경이라 맞지 않음
