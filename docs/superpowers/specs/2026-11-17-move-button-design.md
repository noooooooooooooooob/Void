# 이동 버튼 (2026-11-17)

## 왜
카드·아이템을 안 고른 동안 이동 가능 칸(하늘색)이 항상 켜져 있어 화면이 어지럽다. 버튼을 눌렀을 때만 이동하게 한다 (사용자 요청).

## 접근
전투 화면(`battle_screen.gd`)에 "이동 모드" 하나를 둔다. 규칙(BattleSession.move/reachable_cells)은 그대로.
다른 방법(이동 칸 대신 유닛 클릭으로 모드 진입 등)은 사용자가 버튼을 원해서 제외.

## 동작 (사용자 승인)
- 씬 `BottomRight` 의 가방 버튼 앞에 **이동** 버튼(`MoveButton`, toggle_mode) — 위치는 내 판단
- 평소에는 이동 칸을 표시하지 않고, 칸을 눌러도 이동하지 않는다
- 버튼 → 이동 모드: 갈 수 있는 칸 하늘색, 버튼 눌린 모양
- 이동 모드에서 칸 클릭 → 이동하고 모드 꺼짐 (이동력이 남으면 다시 눌러야 함 — 내 판단, 승인됨)
- 꺼짐: 버튼 다시 누름 / ESC·우클릭 / 카드 고르기 / 아이템 고르기 / 차례 종료
- 버튼 비활성: 이동력 0, 입력 불가(적 차례·연출 중·전투 끝)
- 단축키 없음
